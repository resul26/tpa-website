为全球基础设施建设释放世界级装备制造产能

环太平洋联盟(TPA)面向拉丁美洲、澳大利亚及全球重大能源、矿业和工业基础设施项目,提供经ASME U认证的一流制造能力对接。

  • 大规模制造产能 — 直接对接年产40,000吨重型钢结构、工艺管道及压力容器产能,厂房总面积131,000平方米。
  • 西方标准对标 — 从第一天起,投标方案、合同及执行框架直接对标ASME、AWS、ISO及客户技术规范要求。
  • 优化的商务执行 — 精简的全球化架构,提供极具竞争力的到岸项目价格,并在重大招标中实现高效的商务执行。

高管级质量与技术领导力

"在环太平洋联盟,我们不仅理解质量——我们的公司就建立在质量之上。"

TPA由一位英国高级QA/QC专家创立,拥有超过20年国际油气及矿业重大资本项目一线执行经验,在商务层面提供无与伦比的技术管控能力。

环太平洋联盟为您提供直达工厂层的通道,并由顶级国际资质背书:

  • NACE / AMPP CIP 3级 高级涂装检验师
  • API 510 压力容器检验师
  • API 570 管道检验师
  • CSWIP 3.2 高级焊接检验师
  • CSWIP RI 射线底片评定
  • CSWIP AUT 自动超声波检测数据评定

我们在切割钢材之前,早已解决了技术规格冲突、审核了ITP检验试验计划、评估了PQR/WPS焊接工艺及焊工资格(WPQ),并完成了质量审计——确保您的设备远超基础规范要求,能够经受世界上最严酷工况环境的长期考验。
